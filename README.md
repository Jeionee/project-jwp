## 🌟 Tentang Proyek

Proyek ini dikembangkan sebagai pemenuhan studi kasus sistem informasi manajemen data pegawai yang dilengkapi dengan fitur **CRUD (Create, Read, Update, Delete)** interaktif serta **Dashboard Visualisasi Data** berbasis grafik batang. 
Dirancang dengan gaya antarmuka modern yang bersih (*clean minimalist UI* terinspirasi dari desain profesional), aplikasi ini memastikan pengalaman pengguna yang intuitif dalam memantau statistik kepegawaian secara *real-time*.

---
## ✨ Fitur Utama
- **📊 Dashboard Statistik Interaktif**: Dilengkapi dengan grafik batang (*bar chart*) dinamis yang mencakup:
  - Perbandingan jumlah pegawai berdasarkan **Jenis Kelamin (Laki-laki & Perempuan)**.
  - Distribusi tingkat **Pendidikan Terakhir** pegawai.
  - Pengelompokan kategori **Usia Pegawai**.
- **📈 Kartu KPI Ringkasan Metrik**: Metrik cepat untuk melihat total pegawai, pembagian gender, dan rata-rata usia secara sekilas.
- **📝 Sistem CRUD Lengkap**:
  - **Tambah & Edit**: Formulir modal interaktif untuk memasukkan serta memperbarui data pegawai.
  - **Hapus dengan Konfirmasi Modal**: Mencegah penghapusan tidak sengaja melalui pop-up peringatan visual yang modern.
- **💾 Penyimpanan Lokal (`LocalStorage`)**: Data yang dimasukkan tersimpan secara aman langsung di browser pengguna tanpa memerlukan konfigurasi database yang rumit di awal.

---
## 🛠️ Teknologi yang Digunakan
* **Frontend**: HTML5, Vanilla JavaScript (ES6+)
* **Styling**: Tailwind CSS (Utility-first CSS Framework)
* **Library Grafik**: Chart.js
